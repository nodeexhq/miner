# Reporting a vulnerability

Write to **hello@nodeex.com** with what you found and how to reproduce it. Please do not open a public issue for a
vulnerability, and give us a reasonable time to fix it before you publish.

In scope: this repository, and how the platform at `app.nodeex.com` treats what this program sends. Out of scope:
attacks that need the machine owner's own account on the Mac, since the owner controls the machine.

There is no bug bounty.
